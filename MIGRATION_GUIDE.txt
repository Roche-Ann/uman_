DATABASE MIGRATION GUIDE
========================

To fix the "Unknown column 'disconnection_reason'" error, follow these steps:

OPTION 1: Automatic Migration (RECOMMENDED)
============================================

1. Open your browser and navigate to:
   http://localhost/system/api/add_columns.php

2. The script will automatically add the missing columns to your database:
   - disconnection_reason
   - previous_account

3. You should see a success message like:
   "✓ Added disconnection_reason column
    ✓ Added previous_account column
    Database migration completed successfully!"

OPTION 2: Manual Migration (via phpMyAdmin)
============================================

1. Open phpMyAdmin at http://localhost/phpmyadmin/

2. Select the 'utility_system' database

3. Find the 'service_requests' table

4. Click on the 'SQL' tab

5. Run the following SQL commands:

   ALTER TABLE service_requests 
   ADD COLUMN disconnection_reason text DEFAULT NULL AFTER email;

   ALTER TABLE service_requests 
   ADD COLUMN previous_account varchar(100) DEFAULT NULL AFTER disconnection_reason;

6. Click 'Go' to execute

TESTING
=======

After applying the migration:

1. Try submitting a disconnection request with a reason
2. Try submitting a reconnection request with a previous account number
3. All requests should now submit successfully without database errors

If you still encounter issues:
- Verify you're using the 'utility_system' database (not 'lgu_portal')
- Check that the columns were created correctly in phpMyAdmin
- Clear your browser cache and try again
